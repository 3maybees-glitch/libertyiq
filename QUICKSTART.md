# Quick Start Guide

## Installation

```bash
# Clone or open the project
cd conservative-field-guide

# Install dependencies
pnpm install

# Start development server
pnpm dev
```

Visit `http://localhost:3000` in your browser.

## First Time Use

1. **Browse Topics**: You'll see 3 main topics on the home page
   - Pro-Life Position
   - Immigration and Border Control
   - Second Amendment and Gun Rights

2. **Search**: Use the search bar to find specific topics, arguments, or concepts

3. **Explore Arguments**: Click on any topic card to view all arguments

4. **Expand Details**: Click an argument to see:
   - Full argument text
   - Foundations (Biblical, Scientific, Moral, Historical)
   - Defense points for debate
   - Supporting sources

5. **Track Progress**: Check the checkbox next to each argument to mark it as read

## Troubleshooting

**Progress not saving?**
- Progress is stored locally in your browser
- Try refreshing the page
- Check if you're in private/incognito mode

**Search not working?**
- Ensure JavaScript is enabled
- Try a simpler search term
- Refresh the page

**Page looks different?**
- Clear your browser cache
- Try a different browser
- Check browser zoom level (should be 100%)

## Data Storage

All your progress is stored locally:
- **Preferred**: IndexedDB (modern, large capacity)
- **Fallback**: localStorage (simpler, smaller capacity)
- **Privacy**: No data sent to any server

## Display Optimization

- Tablet: 768px+ width
- Mobile: Works optimally on iPhone 6+ and larger
